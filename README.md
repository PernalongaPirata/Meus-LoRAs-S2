### 📝 Sobre o Projeto

O **Meus LoRAs S2** é um gerenciador local projetado para organizar bibliotecas de LoRAs de Inteligência Artificial. Ele permite catalogar modelos e personagens em uma interface limpa e intuitiva, mantendo todas as *trigger words*, configurações e detalhes de roupas/itens a um clique de distância para facilitar o fluxo de trabalho na geração de imagens. O aplicativo foi construído para ser utilizado em conjunto com o `pywebview`, salvando os dados automaticamente de forma local.

### ✨ Principais Funcionalidades

* **Organização em Categorias e Fichas:** Crie categorias para diferentes séries ou estilos e adicione fichas (cards) individuais para cada personagem ou modelo.


* **Detalhes Completos do Modelo:** Cada ficha armazena informações essenciais, incluindo Link do Modelo, Modelo Base (ex: Illustrious, Pony, etc.), marcação de conteúdo (NSFW: Sim, Não, Sim/Não) e a força recomendada ("Strength", suportando valores únicos, intervalos ou textos customizados).


* **Gerenciador de Prompts (Copiar e Colar Rápido):** Registre múltiplas *Trigger Words* e descrições de Itens/Roupas/Objetos. A interface possui botões dedicados para copiar esses termos rapidamente para a área de transferência.


* **Salvamento Automático (Auto-save):** Todas as alterações feitas na interface são enviadas automaticamente para o backend salvar em um arquivo local, sem necessidade de botões de salvar.


* **Interface Altamente Customizável:**
* Suporte a Temas Claro e Escuro.


* Sistema Multilíngue integrado (Português, Inglês e Espanhol).


* Layout responsivo com controle de grade, permitindo exibir 3, 4 ou 5 colunas de fichas.




* **Busca Rápida:** Uma barra de pesquisa global permite filtrar e encontrar categorias ou fichas específicas instantaneamente.


* **Menu de Contexto:** Suporte a clique com o botão direito para ações rápidas, como duplicar fichas (com incremento automático de numeração, ex: 01 para 02), excluir itens ou criar novas categorias.



### 🛠️ Tecnologias

* **Front-end:** HTML5, CSS3 (variáveis e propriedades modernas, esquema de cores dinâmico) e JavaScript puro (Vanilla JS).


* **Back-end Alvo:** Python utilizando a biblioteca `pywebview` para renderizar a interface como um aplicativo de desktop.
